# Carpeta `config`

Aqui estan los archivos de configuracion de Laravel y paquetes instalados.

Estos archivos leen valores del `.env` y los convierten en configuracion usable por la aplicacion.

No se deben guardar claves reales dentro de esta carpeta; las credenciales deben ir en `.env` o en el modulo de Conexiones cuando sean administradas desde el panel.
