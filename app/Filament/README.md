# Carpeta `app/Filament`

Aqui esta el panel administrativo construido con Filament.

Filament genera el frontend del sistema: menu lateral, formularios, tablas, filtros, acciones y pantallas CRUD.

El panel principal esta disponible en:

```text
/admin
```

Las carpetas mas importantes son:

- `Resources`: modulos CRUD del menu lateral.
- `Pages`: paginas personalizadas del panel, si se agregan.
- `Widgets`: tarjetas o graficas del dashboard, si se agregan.
