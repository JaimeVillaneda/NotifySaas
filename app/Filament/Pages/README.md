# Carpeta `app/Filament/Pages`

Aqui viven paginas personalizadas del panel Filament que no son un CRUD normal.

Actualmente contiene:

- `ConnectionSettings`: pagina del modulo Conexiones. Muestra tres pestanas dentro del mismo modulo: Telegram, Email SMTP y WhatsApp Evolution API.

Se usa una pagina personalizada porque las conexiones se configuran directamente, no como una lista de registros que el usuario tenga que crear manualmente.
