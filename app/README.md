# Carpeta `app`

Aqui vive el codigo principal de la aplicacion Laravel.

- `Models`: clases que representan tablas de la base de datos.
- `Filament`: panel administrativo, modulos laterales, formularios y tablas.
- `Filament/Pages`: pantallas especiales como la configuracion por pestanas de conexiones.
- `Services`: integraciones y logica tecnica reutilizable.
- `Console`: comandos que se ejecutan por terminal o por el programador de tareas.
- `Providers`: clases que registran y configuran servicios de Laravel.

En la sustentacion, esta carpeta se puede explicar como el nucleo de la logica de negocio.
