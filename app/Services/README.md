# Carpeta `app/Services`

Aqui se ubican servicios reutilizables para integraciones o procesos tecnicos.

Actualmente contiene:

- `EvolutionApiService`: prepara el cliente HTTP y envia mensajes de texto por WhatsApp usando Evolution API.

La idea de esta carpeta es separar la comunicacion con servicios externos de los modelos y del panel Filament.
