# Carpeta `app/Http`

Esta carpeta normalmente contiene controladores, middleware y requests HTTP.

En esta version, el flujo visual principal fue migrado a Filament, por eso casi toda la administracion vive en `app/Filament` y no en controladores Blade tradicionales.

Se conserva la carpeta para mantener la estructura estandar de Laravel y para futuros endpoints o controladores API.
